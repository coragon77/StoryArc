== YOUR TASK ==

Report the character's appearance: what lasts, the body and lasting marks, as the texts state them. One item per kind, for these kinds:
- "ethnicity": heritage or ethnicity, only as the text names it ("Indian")
- "skin": skin tone or complexion ("warm brown")
- "hair": colour, length, texture, a lasting style ("dark glossy curls, about shoulder length")
- "eyes": eye colour and shape ("warm brown")
- "build": height and body ("petite, five-two")
- "features": lasting marks, all in one list: scars, tattoos, freckles, birthmarks, piercings, glasses, a beard ("freckles; scar over the left eyebrow")

Rules:
- Never clothing, shoes, jewellery worn for the day, makeup, or a passing state: wet hair, hair up for the evening, wide eyes, a flush, a bruise that will heal.
- Ethnicity only when the text names it, never from a name, a skin tone or a look.
- Never a guess. A kind the texts do not state is left out.
- "features" is one list: write every lasting mark the texts state in one value.
- A value leaves out the kind's own word: "dark glossy curls", not "dark glossy curls hair"; "warm brown", not "warm brown eyes".
- For each kind, the latest value the texts state: when the look changes (a haircut), the newer passage wins. A passage is newer than everything written before the story: when a passage and the persona, card or lorebook disagree, the passage wins. They fill in what the passages never state. When texts add to each other ("dark glossy curls" in one, "shoulder length" in another), combine them into one value.
- "sources": every text the value uses, each one: a passage's message index as a number (2825), a text written before the story by its label as a string ("persona", "card", "lore 2"). A value combined from several texts lists them all: [2825, "persona"].
