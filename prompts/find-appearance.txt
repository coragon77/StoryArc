== YOUR TASK ==

Report what the texts state about the character. One item per kind, for these kinds:
- "gender": as the text states it; the pronouns the text uses for the character ("he", "she") state it too
- "age": as exact or as vague as the text puts it: "18", "twenty-something"
- "role": the job or place in the world, plus where it puts them: "cleaner, double shifts, Oakland"
- "ethnicity": heritage or ethnicity, only as the text names it ("Indian")
- "skin": skin tone or complexion ("warm brown")
- "hair": colour, length, texture, a lasting style ("dark glossy curls, about shoulder length")
- "eyes": eye colour and shape ("warm brown")
- "build": height and body ("petite, five-two")
- "features": lasting marks, all in one list: scars, tattoos, freckles, birthmarks, piercings, glasses, a beard ("freckles; scar over the left eyebrow")

Rules:
- Record only what the text states. Never guess a detail from a name, a look, a trope or what would be likely. A kind the texts do not state is left out.
- An age exactly as the text states it, never worked out from other facts.
- For the looks (ethnicity, skin, hair, eyes, build, features), what lasts, the body and lasting marks: never clothing, shoes, jewellery worn for the day, makeup, or a passing state: wet hair, hair up for the evening, wide eyes, a flush, a bruise that will heal.
- Ethnicity only when the text names it, never from a name, a skin tone or a look.
- "features" is one list: write every lasting mark the texts state in one value.
- A look's value leaves out the kind's own word: "dark glossy curls", not "dark glossy curls hair"; "warm brown", not "warm brown eyes".
- For each kind, the latest value the texts state: when it changes (a haircut, a birthday, a new job), the newer passage wins. A passage is newer than everything written before the story: when a passage and the persona, card or lorebook disagree, the passage wins. They fill in what the passages never state. When texts add to each other ("dark glossy curls" in one, "shoulder length" in another), combine them into one value.
- "value" is always a string, a few words.
- "sources": every text the value uses, each one: a passage's message index as a number (2825), a text written before the story by its label as a string ("persona", "card", "lore 2"). A value combined from several texts lists them all: [2825, "persona"].
