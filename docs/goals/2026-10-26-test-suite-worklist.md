# StoryArc test-suite worklist (mutation audit, 2026-10-26)

**Status:** done (C1–C5) · **Opened / last verified:** 2026-10-26 · **Scale:** 51 hollow function groups, 4 untested groups; several fixing sessions

This is a goals document, not a spec; chapters go through the normal spec/plan workflow.

## Why

The StoryArc suite is green. It has 292 tests and covers 88% of the lines it imports. Agents wrote it quickly, and nobody has checked what it asserts.

A mutation run shows that the suite misses 423 of 1953 code changes in `lib/`. The misses are not in rarely used corners. They are in the prompt that goes to the model on every message:

- the injection header that the stamping code searches for
- the pacing directive
- the secret and trigger filters
- the beat unlock rule and the mark queue

A regression there changes what the narrating model is told, and nothing goes red.

## Scope

In scope: stronger tests for the 51 hollow function groups and new tests for the 4 untested groups. The **Findings** table gives the contract for each.

Out of scope: the files that the mutation run left out (see the facts table), and the JS front end for the audit scanner. That front end belongs to the `unittest-audit` skill, which lives in a separate skills repository.

## Decided

- **The audit runs on StoryArc through Stryker, not through the Python scanner.** The project has no Python. Stefan: "This project does not use python asfaik". Stefan approved the plan on 2026-10-26 with "yes, lets go with your recommendations." That approval covered the Stryker trial on the covered files, the pinned install, and the later JS front end and JS mutation path for the skill.
- **No entry is ever a bare deletion.** A hollow test gets the assertion it should have had. A duplicate is merged into the test that is kept. Source: the `unittest-audit` skill ("No entry in this worklist is ever a bare deletion, whatever its verdict").
- **Tests pin a few anchor phrases per prompt block, not every line.** Most surviving string mutants delete one line of prose from a prompt block (`signal-directive.js`, `tier-block.js`, `episode.js`). Pinning every line would fail the tests on every wording edit. Stefan accepted this on 2026-10-26: "yes to your recommendations - go ahead with subagents".
- **The next mutation run adds `lib/ui/progress.js` only.** `generator.js`, `templates.js` and `chat-history.js` stay out. Accepted with the same words on 2026-10-26.
